# Library Management System

A simple Library Management System built using **Python** and **PostgreSQL**.  
This project demonstrates database connectivity, table creation, and basic library operations using Python.

## Features

- Add new books
- View available books
- Issue books
- Return books
- Update quantity automatically
- PostgreSQL database integration
- Modular Python structure

## Technologies Used

- Python
- PostgreSQL
- psycopg2
